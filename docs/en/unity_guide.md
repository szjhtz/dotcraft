# Unity Integration

The Unity editor client now lives in its own repository:

[DotHarness/dotcraft-unity](https://github.com/DotHarness/dotcraft-unity)

DotCraft remains the agent harness that the Unity client starts through ACP. Install and configure DotCraft from this repository first, then add `dotcraft-unity` to your Unity project:

```text
https://github.com/DotHarness/dotcraft-unity.git
```
